# DAYSTACK

**DAYSTACK is an all-in-one productivity tracker to plan your day, build habits, manage goals, track progress, stay focused, and organize your life in one place.**

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in `.env` to your Gemini API key (see `.env.example`).
3. Run the app:
   `npm run dev`
